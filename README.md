**Setup**

- Ensure Terraria and tModLoader are installed
- Extract the zip at the (Windows) path '...\Documents\My Games\Terraria\tModLoader\ModSources\Hell Plus', you will need to create any new folders as necessary
- Open tModLoader, navigate Workshop -> Manage Mods -> Enable HellPlus v0.0.2
- Play the game, with a new character and world if needed

**Playing**

- HellPlus is a mod that adds new items, blocks and features to Terraria
- In order to access these, using a cheat mod such as 'HERO's Mod' is recommended in order to test everything at once
- Otherwise, they can be found and discovered through normal gameplay like a new player would
